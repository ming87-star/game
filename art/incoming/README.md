# 아직 안 얹은 그림

바깥에서 받아 온 원본과, `crop-ui.js` 로 **잘라서 알파를 입힌 것**들입니다.
게임에는 아직 하나도 안 붙였습니다 — 고른 뒤에 `art/` 로 옮겨야 붙습니다.

## 원본

| 파일 | 크기 | 무엇 |
|---|---|---|
| `../title.png` | 1448×1086 | 제목 글자 (보라 탑) |
| `../hint.png` | 2172×724 | 「터치해서 계속하기」 금테 |

## 잘라 낸 것

검은 바탕에 빛나는 그림은 **밝기가 곧 알파**입니다. 문턱 하나로 자르면
연기 자락이 톱니가 되므로, 밝기를 그대로 알파로 옮겼습니다.

| 파일 | 크기 | 결 |
|---|---|---|
| `title-soft.webp` | 1446×1000 (1.45:1) | 연기가 멀리까지 남음 · 탑의 돌이 조금 비침 |
| `title-solid.webp` | 〃 | 탑이 단단함 · 연기 바깥 자락이 조금 일찍 끊김 |
| `hint-soft.webp` | 1916×404 (4.74:1) | 판때기 검게 꽉 참 · 좁게 흐림 |
| `hint-soft-glass.webp` | 〃 | 판때기 반쯤 비침 · 좁게 흐림 |
| `hint-medium.webp` | 〃 | 꽉 참 · 보통 |
| `hint-medium-glass.webp` | 〃 | 반쯤 비침 · 보통 |

`wide` 두 벌은 흐리는 폭이 너무 넓어 금테 좌우 끝이 날아가서 버렸습니다.

## 「터치해서」는 안과 밖을 가르는 일이 있었습니다

금테 **안쪽 판이 바깥 배경과 같은 검정**이라, 밝기만으로 뽑으면 판이 통째로
비고 다 채우면 바깥까지 살아서 검은 상자가 됩니다. 그래서 **금테 자신을
벽으로 삼아** 가장자리에서 어두운 곳만 타고 번져 들어갑니다 — 금테에 막혀
안쪽에는 못 들어가므로, 닿은 곳이 바깥이고 안 닿은 곳이 안입니다.

다시 자르려면:

```
CHROME_PATH=... node crop-ui.js title art/title.png
CHROME_PATH=... node crop-ui.js hint  art/hint.png
```
