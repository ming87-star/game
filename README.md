# 탑 오르기

주인공이 탑을 올라갑니다. 화면 **왼쪽 / 오른쪽을 누르면 그쪽 발판으로 점프**합니다.
점프는 실패하지 않습니다 — 좌우는 난이도가 아니라 **어느 길로 갈지 고르는** 조작입니다.
무기는 자동으로 나갑니다.

빌드 도구 없이 돌아갑니다.

```
git clone https://github.com/ming87-star/game
cd game
# index.html 더블클릭  (또는)
npx serve .
```

## 지금 있는 것

| | |
|---|---|
| 조작 | 화면 좌/우 탭 (PC는 ← → 키) |
| 전투 | 사거리 안의 적을 자동 공격 |
| 무기 | 8단계 — 녹슨 단검 … 용살검 |
| 강화 | `+1` 공격력 · `×2` 발사체 수 · `UP` 다음 무기 |
| 적 | 6종 — 기는 것, 단단한 놈, 날것, 빠른 놈, 거인, 사수 |
| 코인 | 적을 잡으면 떨어지고, 50층마다 상점에서 씁니다 |
| 아이템 수명 | 가까이 가면 시계가 돌기 시작해 깜빡이다가 사라집니다 |
| 끝 | 체력 0에서 사망, 화면을 누르면 재시작 |

그림은 아직 없습니다. 도형을 코드로 그려서 씁니다 (`js/textures.js`).
진짜 그림이 나오면 이 파일을 걷어내고 `load.image()`로 바꾸면 됩니다.
발판 위 아이템 표시도 지금은 글자(`+1`, `×2`, `UP`)라서, 그림이 생기면
`scene-game.js`의 `makeMark()` 한 곳만 바꾸면 됩니다.

## 무엇을 고르게 만들 것인가

이 게임의 입력은 좌우 탭 하나뿐입니다. 그래서 **고를 거리가 있느냐**가 전부입니다.
지금 세 겹으로 깔려 있습니다.

**어느 발판으로 갈까.** 발판 위에 무엇이 있는지 올라가기 전에 보입니다.
`⚠ 3`은 적 세 마리, 나머지는 아이템입니다. 한 층의 좌우가 같은 내용이면
한쪽을 다시 굴려서, 늘 다른 것 사이에서 고르게 합니다.

**계속 키울까, 갈아탈까.** `+1`과 `×2`는 지금 무기를 키웁니다. `UP`은 다음 단계
무기를 주지만 **쌓아둔 강화를 전부 잃습니다.** 그래서 `+12`까지 키운 강철 검을
들고 있다면 UP이 오히려 손해입니다. 언제 갈아탈지가 판단입니다.

**적을 피할까, 잡을까.** 적은 코인을 떨굽니다. 코인은 50층 상점에서 강화가 됩니다.
안전하게 지나가면 상점에서 살 게 없습니다.

그리고 **버티는 것이 이득이 되지 않게** 해 뒀습니다. 발판 위 아이템은 주인공이
`armWithin` 층 안으로 들어오면 시계가 돌기 시작해, `blinkAt`부터 깜빡이다가
`life`에 사라집니다. 자리를 잡고 적을 잡아 모으는 것보다 빨리 오르는 편이
이득이 되게 하려는 장치입니다. 상점에 머문 시간은 세지 않습니다.

## 밸런스 확인

사람처럼 고르는 가상 플레이어를 헤드리스 브라우저에 태워 올려보냅니다.
층별 체력·적 수·처치·코인·무기 상태를 찍어주고, 화면도 `shots/`에 저장합니다.
상점이 열리면 실제 버튼 좌표를 눌러서 UI가 입력을 받는지까지 확인합니다.

```
npm install
npm run playtest        # 60번 점프
node playtest.js 130    # 더 높이
```

수치를 만질 때마다 서너 번 돌려 보세요. 한 번으로는 운인지 밸런스인지 구분이 안 됩니다.
현재 기준으로는 **50~125층**에서 갈리고, 첫 상점(50층)은 대체로 봅니다.

밸런스를 잡으며 걸렸던 것들 — 나중에 수치를 만질 때 같은 함정에 빠지지 않도록:

- **자동 공격은 한 번 노린 적을 끝까지 노립니다.** 매 발 가장 가까운 적으로
  갈아타면 피해가 흩어져 30마리를 쌓아두고 한 마리도 못 잡습니다.
- **`×2`에는 상한이 있습니다** (`maxMult`). 두 배가 계속 겹치면 지수로 늘어나
  40층에서 12발이 나갑니다.
- **적 체력은 곱으로 자랍니다** (`hpGrowth`). 주인공의 화력도 강화가 겹치며
  곱으로 자라기 때문에, 더하기로만 올리면 어느 층부터 아무것도 위협이 안 됩니다.
- **적 공격력도 같이 올라야 합니다** (`dmgPerFloor`). 체력만 올리면
  못 죽이는데 죽지도 않는 교착이 됩니다.

## 한 파일로 합치기

```
npm run build              # dist/index.html — 그대로 열리는 완성 파일
node build.js --fragment   # dist/artifact.html — 문서 껍데기 없는 조각
```

Phaser와 게임 코드를 전부 인라인해서 파일 하나로 만듭니다. 폰에 링크로 보내
눌러보게 하거나 정적 호스팅에 올릴 때 씁니다.
