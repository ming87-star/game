# 탑 오르기

주인공이 탑을 올라갑니다. 화면 **왼쪽 / 오른쪽을 누르면 그쪽 발판으로 점프**합니다.
점프는 실패하지 않습니다 — 좌우는 난이도가 아니라 **어느 길로 갈지 고르는** 조작입니다.
무기는 자동으로 나갑니다.

빌드 도구 없이 돌아갑니다.

```
git clone https://github.com/ming87-star/game
cd game
# index.html 더블클릭  (또는)
npx serve .
```

## 지금 있는 것

| | |
|---|---|
| 조작 | 화면 좌/우 탭 (PC는 ← → 키) |
| 전투 | 사거리 안의 적을 자동 공격 |
| 성장 | 무기 8단계 — 녹슨 단검 … 용살검 |
| 적 | 발판에 배치 + 높이 올라갈수록 잦아지는 무작위 등장 |
| 끝 | 체력 0에서 사망, 화면을 누르면 재시작 |

그림은 아직 없습니다. 도형을 코드로 그려서 씁니다 (`js/textures.js`).
진짜 그림이 나오면 이 파일을 걷어내고 `load.image()`로 바꾸면 됩니다.

## 좌우 선택이 의미를 갖게 하는 장치

발판 위에 무엇이 있는지 **올라가기 전에 보입니다.** 노란 마름모는 무기 아이템,
초록 십자는 회복, `⚠ 3`은 적 세 마리입니다.

무기는 두 갈래로 자랍니다.

- 아이템을 먹으면 1점
- 적을 `killsPerPoint`마리 잡으면 1점
- `pointsPerLevel`점마다 한 단계

아이템으로만 자라게 하면 적 발판은 무조건 피하는 게 정답이라 선택이 사라집니다.
처치로도 자라기 때문에 **안전한 성장(아이템)과 위험한 성장(적)** 사이에 저울질이 생깁니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `js/config.js` | 모든 수치. 밸런스는 여기만 고칩니다 |
| `js/tower.js` | 층·발판·내용물 생성 (그리기와 분리된 순수 로직) |
| `js/textures.js` | 도형으로 그림 만들기 |
| `js/scene-game.js` | 게임 본체 |
| `js/main.js` | Phaser 설정 |

## 밸런스 확인

사람처럼 고르는 가상 플레이어를 헤드리스 브라우저에 태워 45층까지 올려봅니다.
층별 체력·처치·무기·적 수를 찍어주고, 화면도 `shots/`에 저장합니다.

```
npm install
npm run playtest
```

수치를 만질 때마다 서너 번 돌려 보세요. 한 번으로는 운인지 밸런스인지 구분이 안 됩니다.
현재 기준으로는 **30~45층에서 사망**하고, 그동안 무기가 뇌전검 언저리까지 올라갑니다.

## 한 파일로 합치기

```
npm run build          # dist/index.html — 그대로 열리는 완성 파일
node build.js --fragment   # dist/artifact.html — 문서 껍데기 없는 조각
```

Phaser와 게임 코드를 전부 인라인해서 파일 하나로 만듭니다. 폰에 링크로 보내
눌러보게 하거나 정적 호스팅에 올릴 때 씁니다.
